# Cars 1st Birthday Invitation

A responsive, mobile-friendly 1st birthday invitation with a cars / racing theme.

- `index.html`: hero + countdown, meet the driver, race day pass + map, dress code, Photo Finish gallery with zoom, RSVP
- `css/cars.css`: colors are CSS variables at the top (`:root`)
- `js/cars.js`: edit the `EVENT` block at the top (baby name, date/time, venue) for the countdown and calendar file
- `images/cars/`: original car illustrations (SVG)
- `images/photos/`: add `baby.jpg` (main photo) and `baby.jpg` (Meet the Little Driver), `family.jpg` (family billboard) and `gallery-01.jpg` ... (Photo Finish, tap to zoom).

Also replace "Baby Name" in `index.html` (search for it), and update the date, venue and program text there.
Open `index.html` in a browser to preview. No build step is needed.

Gift guide: edit the three cards in the `#gifts` section of `index.html` (monetary gift, shoes size 22 cm, clothes for 2 years old).
